# EFYL-RidePooling-2026
RidePooling EFYL : solution de transport collectif par moto-taxis et taxis, reliant les passagers aux chauffeurs déjà en course selon la compatibilité des itinéraires. Demandes via application, USSD ou WhatsApp, dépôt précis via AddressBook, tarification kilométrique dégressive et paiements numériques synchronisés avec ObitERP.
